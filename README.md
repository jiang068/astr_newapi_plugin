# AstrBot NewAPI 站点查询与管理插件 (astr_newapi_plugin)

为 AstrBot 量身定制的 **NewAPI** 站点信息查询与全能管理插件。
支持用户绑定自己的账号查询用量、余额与订阅，提供全站消费统计和排行图表，并使用中文菜单与暗色卡片展示结果。

---

## 🌟 核心特性

1. **👥 所有人自主绑定账号**：
   - 普通群友/用户可通过 `/newapi 绑定 <用户名或编号>` 将自己的聊天身份与 NewAPI 账号绑定。
   - 绑定后，发送 `/newapi 个人` 即可查询余额、累计消费、请求数及订阅到期时间。未绑定时不会显示机器人访问令牌所属账号的信息。
2. **💾 规范化数据存储与一键备份导出**：
   - 数据保存于 AstrBot 插件数据目录：`data/plugin_data/astr_newapi_plugin/`。
   - 管理员发送 `/newapi 备份` 可导出用户绑定、站点缓存和配置副本；发送 `/newapi 恢复` 可从备份恢复。
3. **🎨 动静分离渲染（信息多时暗色画图，少时文字速回）**：
   - 菜单、用户排行、模型排行、站点状态和渠道列表可生成暗色卡片；账户信息、兑换码和管理操作以文字回复。
   - 用户排行显示相对消费条形图；模型排行显示词元数条形图和厂商份额饼图。
4. **🖥️ 状态监控读取 NewAPI 远程数据**：
   - `/newapi 状态` 从 NewAPI 性能接口读取远程进程内存和缓存目录所在磁盘空间；接口未提供的指标显示“暂不可获取”，不会使用 AstrBot 本机数据代替。
   - 菜单、统计和排行标题优先使用 NewAPI `/api/status` 返回的站点名称；获取失败时回退到配置地址中的域名。
5. **🔤 灵活的前缀与中英文指令兼容**：
   - 菜单和设置说明以中文为主；原有英文命令别名仍可兼容使用。
   - 支持空格形式和原有紧凑别名，例如 `/newapi 余额` 与 `/newapi余额`。
6. **🔐 管理权限控制**：
   - 管理功能关闭或非机器人管理员调用管理指令时，插件会返回权限提示；普通查询仍可使用。

## ⚙️ 配置说明

在 AstrBot 控制面板的 **插件管理** 页面配置以下参数：

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :---: | :---: | :--- |
| `site_url` | 字符串 | `""` | NewAPI 站点地址，例如 `https://api.example.com` 或 `http://127.0.0.1:3000` |
| `api_token` | 字符串 | `""` | 填写具有管理权限的 NewAPI 访问令牌；性能监控需超级管理员权限，不能填写普通模型调用密钥 |
| `api_user_id` | 字符串 | `""` | 填写访问令牌所属账户的数字用户编号，可从 `GET /api/user/self` 返回内容的 `data.id` 获取 |
| `enable_admin` | 布尔值 | `true` | 是否启用管理功能。关闭后管理指令会提示当前状态 |
| `admin_only` | 布尔值 | `true` | 管理类指令是否仅限 AstrBot 机器人管理员调用 |
| `request_timeout` | 整数 | `15` | 请求 NewAPI 超时时间（秒） |
| `proxy` | 字符串 | `""` | 可选网络代理地址 |
| `quota_per_unit` | 整数 | `500000` | 1 美元对应的额度点数（插件会自动从站点获取） |

> 📁 **官方数据持久化目录**：
> `data/plugin_data/astr_newapi_plugin/`
> - `user_bindings.json`：用户聊天 ID 与 NewAPI 账号映射
> - `cache.json`：站点缓存与换算比例
> - `config_backup.json`：配置参数安全备份
> - `backups/`：备份文件归档目录（存储自动生成的 `.zip` 压缩包）

## 📖 指令对照表

菜单默认展示中文指令；原有英文名称继续作为兼容别名。支持 `/newapi 余额` 和 `/newapi余额` 两种写法。

### 1. 👥 用户查询与绑定指令
| 指令格式（中英均可，支持有/无空格） | 参数 | 返回形式 | 功能说明 |
| :--- | :--- | :---: | :--- |
| `/newapi 菜单` | 无 | 🖼️ 暗色卡片 | 展示可用功能和中文指令 |
| `/newapi 绑定` | `<用户名或用户编号>` | 📝 文字 | 绑定个人的 NewAPI 账号 |
| `/newapi 解绑` | 无 | 📝 文字 | 解除当前账号绑定 |
| `/newapi 个人` 或 `/newapi 余额` | 无 | 📝 文字 | 查询已绑定账号的余额、消费、请求次数与订阅 |
| `/newapi 我的统计` | `[今天/本周/本月/全部]` | 📝 文字 | 查询已绑定账号的消费统计 |
| `/newapi 全站统计` | `[今天/本周/本月/全部]` | 📝 文字 | 查询全站消费金额和请求速率 |
| `/newapi 用户排行` | `[今天/本周/本月/总计]` | 🖼️ 暗色卡片 | 查看用户消费排行和条形图 |
| `/newapi 模型排行` | `[今日/本周/本月/本年]` | 🖼️ 暗色卡片 | 查看模型词元数排行和厂商份额饼图 |
| `/newapi 状态` | 无 | 🖼️ 暗色卡片 | 查询站点参数和远程性能数据；缺少的指标显示“暂不可获取” |
| `/newapi 兑换` | `<兑换码>` | 📝 文字 | 使用兑换码为当前账号充值 |

| `/newapi 恢复` | `[备份文件名]` | 📝 文字 | 从指定或最新备份恢复数据 |
